# Aryan Kapadiya — 3D Web Developer Portfolio

## Stack
React + Vite + Three.js + React Three Fiber + Drei + Framer Motion + Lucide React.

## Run locally
```bash
npm install
npm run dev
```

## Before publishing
1. Replace `your-email@example.com` in `src/main.jsx`.
2. Replace GitHub and LinkedIn placeholder URLs with your real profiles.
3. Add real project demo/GitHub URLs to the project cards.
4. Add your resume PDF to `public/` and connect the Resume button.
5. Deploy to Vercel or Netlify.

## Build
```bash
npm run build
```
